# LOCAL — Платформа для поиска локальных музыкальных событий

Лендинг и промо-страница мобильного приложения **LOCAL**. Проект помогает пользователям находить концерты локальных артистов и мероприятия в своем городе, а организаторам — добавлять свои события через форму обратной связи.


## 📱 О проекте

**LOCAL** — это сервис, объединяющий любителей музыки и организаторов мероприятий.

- **Для пользователя:** возможность следить за афишей, находить события рядом, открывать новых исполнителей.
- **Для организатора:** бесплатное размещение анонсов после быстрой модерации.

Данный репозиторий содержит код **лендинга**, который презентует преимущества приложения, содержит блоки с функциями, FAQ и форму для сбора заявок от потенциальных организаторов.

## 🚀 Демо и структура

Проект состоит из одностраничного сайта (лендинга) с адаптивной версткой и анимациями.

### Основные блоки:
1.  **Hero:** Заголовок, призыв к действию и мокап приложения.
2.  **Тикеры (бегущие строки):** Динамические ленты с ключевыми сообщениями.
3.  **Особенности:** Описание функционала приложения с визуальными мокапами.
4.  **Разделы для организатора и пользователя:** Подробное описание преимуществ.
5.  **FAQ:** Ответы на частые вопросы (реализованы через `<details>`).
6.  **Форма обратной связи:** Сбор данных (ФИО, телефон) для подключения организаторов.
7.  **Кнопки магазинов приложений:** Ссылки на App Store и Google Play.

## 🛠 Технологии

- **HTML5 / CSS3:**
  - Адаптивная верстка (Mobile First, Bootstrap 5 сетка).
  - Кастомные свойства (CSS Variables) для цветовой схемы.
  - Градиенты, тени, анимации `@keyframes` для бегущих строк.
- **JavaScript (Vanilla):**
  - Регистрация плагина `ScrollTrigger` для анимаций появления элементов.
  - Анимации наведения (GSAP).
- **Библиотеки:**
  - [GSAP](https://greensock.com/gsap/) + ScrollTrigger: плавные анимации при скролле и при наведении.
  - [Bootstrap 5](https://getbootstrap.com/): сетка и базовые утилиты.
  - [Supabase JS Client](https://supabase.com/docs/reference/javascript): отправка данных из формы в базу данных.
- **База данных:** Supabase (PostgreSQL). Схема включает таблицы `contacts` (заявки).
